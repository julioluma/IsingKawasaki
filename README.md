Este repositorio tiene como objetivo la evaluación voluntaria de Física Computacional, estudia diferentes aspectos del modelo Ising-Kawasaki de spines en un metal.
El archivo ejecutable principal es VoluntarioKawasaki.py, que ejecuta la simulación para un valor concreto de T y N.
El archivo VoluntarioKawasaki_diferenteT.py realiza una simulación para cada T y cada N que se le indique; guarda los estados de spines si se le pide en la carpeta spines
Los resultados de E, M_sup, M_inf, c_N, \chi_N se guardan para cada N y T en la carpeta resultados.
El archivo animacion.py anima los spines de la red para un valor de T y N indicados.
grafica.py crea una gráfica de una variable concreta y guarda la gráfica en la carpeta Graficas
graficadensidades.py sirve para realizar las graficas de las distribuciones de spines hacia arriba en cada fila.
graficatiempos.py grafica los diferentes tiempos de ejecución del programa, los datos deben estar en la Carpeta tiempos
